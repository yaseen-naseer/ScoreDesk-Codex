# ScoreDesk Documentation

This directory contains design and specification documents for the ScoreDesk application. The project follows **Spec-Driven Development (SDD)**: every feature is described in a specification before implementation begins.

## Document Structure

- `requirements.md` – Functional requirements and user stories.
- `architecture.md` – High level system architecture and major components.
- `data-model.md` – Database schema and relationships.
- `ui-components.md` – Reusable UI components and theming guidelines.

Each document should be updated as the application evolves. No code should be written without an accompanying specification.
